# 🤝 Code of conduct

[![Participation: respectful](https://img.shields.io/badge/participation-respectful-1D76DB)](CONTRIBUTING.md)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

## 🌱 Expected behavior

Treat contributors, users, and reviewers with respect. Discuss ideas and
evidence constructively, welcome questions, credit others' work, and accept
reasoned corrections. Disagreement about code or methodology is expected;
personal attacks are not.

Harassment, threats, discriminatory or degrading remarks, unwanted personal
contact, deliberate disruption, and disclosure of private information without
permission are unacceptable. Do not retaliate against someone for raising a
concern in good faith.

## 🧭 Scope and moderation

This policy covers this repository's issues, PRs, reviews, discussions, and
other project spaces. It also applies when someone represents this project
in a related public interaction.

I (@danielep71) may request a correction, remove or hide content, lock a
conversation, or restrict participation using GitHub's available
moderation controls. Responses should reflect the behavior, its impact,
and any repeated violations. Technical disagreements alone are not misconduct.

## 📣 Reporting concerns

Use the offending content's menu and select **Report content**. Choose
**Report abuse to GitHub Support** when available; follow
[GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
For a concern about me, use the same GitHub Support route.
Reports to GitHub Support are handled by GitHub, not a private project inbox.
Do not assume a report to GitHub automatically notifies me.

Include a short factual description, links to the relevant content, and
necessary context in the private report. The issue forms are for technical
work, not conduct reports. Do not publish private identities, personal contact
details, or sensitive evidence in issues. Do not contact people repeatedly or
through unrequested personal channels.

Potential vulnerabilities use the separate [security policy](SECURITY.md).
This conduct policy does not authorize investigation of private accounts or
publication of private evidence.
